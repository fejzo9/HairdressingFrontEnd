# Security Policy

## Supported Versions

We are committed to providing security updates for the current version of the Hairdressing Salon Reservation App.

| Version | Supported          |
| ------- | ------------------ |
| v0.x    | :white_check_mark: |
| < v0.x  | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please let us know immediately. Your help in maintaining the security of this application is greatly appreciated.

### How to report
Please report security vulnerabilities by sending an email to **fejzillah.zdralovic@gmail.com**.

### What to expect
- You will receive an acknowledgment of your report within 48 hours.
- We will provide a preliminary analysis and an estimated timeline for a fix within 5 working days.
- Once the vulnerability is resolved, we will notify you and credit you for the discovery (unless you prefer to remain anonymous).

Please do not open GitHub issues for security vulnerabilities, as this exposes the issue publicly before a fix can be applied.
